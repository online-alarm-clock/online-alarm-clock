# Online Alarm Clock

> Online Alarm Clock is a free browser-based collection of time tools. Set alarms, run timers and stopwatches, view world clocks, and convert time zones without installing an app.

The site is available in English and Chinese. Alarm and clock settings are handled in the browser; alarms require the page to remain open and the device to stay awake.

## Tools

- [Online Alarm Clock](https://onlinealarmclock.net/): Set a browser alarm, choose a sound, and manage reminders.
- [Online Timer](https://onlinealarmclock.net/online-timer): Run one or more countdown timers.
- [Online Stopwatch](https://onlinealarmclock.net/online-stopwatch): Measure elapsed time with a browser stopwatch.
- [Countdown Timer](https://onlinealarmclock.net/countdown-timer): Count down to a chosen duration or event.
- [World Clock](https://onlinealarmclock.net/world-clock): Compare live local times for cities around the world and save cities in this browser.
- [Time in London](https://onlinealarmclock.net/world-clock/time-in-london): View London's current local time, time-zone details, daylight-saving information, and a city time converter.
